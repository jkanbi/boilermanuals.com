Free UK boiler manuals, checked against the model

BoilerManuals.com lists 10,017 UK boiler models from 179 brands, each with its GC number where it has one, and links 5,952 of them to one of 2,053 installation, servicing and user manuals (PDF) that you can view online free. Before a manual is linked, we open the PDF and check it names the same model or GC number and the same fuel. Gas and oil boilers, solid fuel and biomass boilers, range cooker boilers and micro-CHP units are listed from the official UK Product Characteristics Database (PCDB); 47.0% of the 7,455 PCDB boilers (all four boiler tables) currently have a manual here. How we check manuals. Looking for a wood pellet, log or range cooker boiler? See solid fuel, biomass, range cooker and micro-CHP manuals.

Common questions

Are the boiler manuals free?

Yes. Every manual on BoilerManuals.com is free to view online, with no registration. Manuals are hosted on our own server (cdn.boilermanuals.com).

How do I find the manual for my boiler?

Type your boiler’s brand, model name or GC number into the search box at the top of the home page, or open the brand page and search its table. Each model row shows its GC number, fuel and a View link when we hold a checked manual.

What is a GC number and where do I find it?

The GC (Gas Council) number is a 7-digit code, written like 47-044-32, that identifies a UK gas boiler model and fuel. It is printed on the boiler’s data badge, usually under or behind the front cover, and in the user manual. Natural gas and LPG versions of the same boiler normally have different GC numbers. Oil and electric boilers do not have GC numbers, so search those by model name.

Does one manual cover both natural gas and LPG?

Sometimes. We only link a natural gas row and an LPG row to the same manual when the PDF itself lists both fuels or the LPG GC number.

What if my manual is not listed?

Use the Request manual link on the model’s row, or email request@boilermanuals.com with the brand, model and GC number. If a link looks wrong, use the Report link on that row.

Can I work on my gas boiler using these manuals?

The manuals are for reference. In the UK, work on a gas boiler must be carried out by an engineer on the Gas Safe Register; follow the safety instructions in the manual.
